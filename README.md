# Simple Pomodoro timer using Qt

- Toggleable start/pause button
- Reset button for starting a new session
- Settings tab for configuring the break/work time

At the moment the only release available is for mac as I havent compiled for other machines

However if you want to run the .py here are the steps

1. Make sure you have pip installed for downloading the depenencies
   You can check by running:
```   
pip --version
```
2. Then once you are in your ide looking at the .py file run
```
pip install
```
(this will install dependencies required to run)
3. Then hit run and there ya go
